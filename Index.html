📝 Text & Formatting Tags

ওয়েবপেজে টেক্সট লেখা এবং সেগুলোকে সাজানোর জন্য প্রয়োজনীয় সব ট্যাগ।

Tag Name বাংলায় কাজ Level
<h1> থেকে <h6> হেডিং বা শিরোনাম লেখার জন্য। h1 সবচেয়ে বড় এবং h6 সবচেয়ে ছোট। (SEO এর জন্য একটি পেজে একটিই h1 রাখা উচিত)। Basic
<p> ... </p> প্যারাগ্রাফ লেখার জন্য। Basic
<br> লাইন ব্রেক বা নতুন লাইনে যাওয়ার জন্য (এর কোনো closing tag নেই - Empty Element)। Basic
<hr> হরাইজন্টাল লাইন বা দাগ টানার জন্য। Basic
<strong> বা <b> টেক্সট বোল্ড (মোটা) করার জন্য। তবে <strong> ব্রাউজারকে বোঝায় যে লেখাটি গুরুত্বপূর্ণ (Semantic)। Basic
<em> বা <i> ইটালিক (বাঁকা) করার জন্য। <em> মানে emphasized text, যা স্ক্রিন রিডাররা জোর দিয়ে পড়ে। Basic
<mark> টেক্সট হাইলাইট করার জন্য (সাধারণত হলুদ ব্যাকগ্রাউন্ড হয়)। Mid
<del> ও <ins> <del> লেখা কেটে দেয় (strikethrough) এবং <ins> লেখার নিচে আন্ডারলাইন করে (inserted)। সাধারণত ই-কমার্স সাইটে ডিসকাউন্ট প্রাইস দেখাতে ব্যবহৃত হয়। Mid
<sup> ও <sub> Superscript (যেমন: X2) এবং Subscript (যেমন: H2O) লেখার জন্য। Mid
<blockquote> ও <q> অন্য কারো উক্তি কোট করার জন্য। <q> ছোট কোটেশনের জন্য এবং <blockquote> বড় কোটেশনের জন্য। Advanced
<code> ও <pre> কম্পিউটার কোড ওয়েবসাইটে দেখানোর জন্য। <pre> ব্যবহার করলে কোডের ভেতরের স্পেস এবং লাইন ব্রেক হুবহু বজায় থাকে। Mid

📝 Forms & Inputs

ইউজার থেকে ডেটা (যেমন: লগইন, রেজিস্ট্রেশন, কন্টাক্ট) নেওয়ার জন্য ফর্ম সবচেয়ে গুরুত্বপূর্ণ।

Input Type ব্যবহার
type="text" সাধারণ লেখা (নাম, ইউজারনেম)।
type="email" ইমেইল নেওয়ার জন্য (অটোমেটিক @ চেক করে)।
type="password" পাসওয়ার্ডের জন্য (লেখাগুলো ডট বা স্টার হয়ে যায়)।
type="number" শুধুমাত্র সংখ্যা নেওয়ার জন্য (বয়স, ফোন নম্বর)।
type="radio" একাধিক অপশন থেকে একটি সিলেক্ট করার জন্য (যেমন: Gender: Male/Female)।
type="checkbox" একাধিক অপশন সিলেক্ট করার জন্য (যেমন: Hobbies)।
type="date" তারিখ নির্বাচন করার জন্য একটি ক্যালেন্ডার পপআপ দেখায়।
type="file" কম্পিউটার থেকে ছবি বা ডকুমেন্ট আপলোড করার জন্য।
HTML Complete Registration Form HTML 
<!-- action: ডেটা কোথায় যাবে, method: GET বা POST -->

    <!-- Label: ইনপুট ফিল্ডের নাম, for এবং id ম্যাচ করতে হবে -->

    <input type="text" id="username" name="user" placeholder="Enter name" required>
    <br><br>

    <label for="pwd">Password:</label>
    <input type="password" id="pwd" name="password">
    <br><br>

    <!-- Radio Button (name এক হতে হবে যাতে একটা সিলেক্ট হয়) -->
    <p>Gender:</p>
    <input type="radio" id="male" name="gender" value="male">
    <label for="male">Male</label>
    <input type="radio" id="female" name="gender" value="female">
    <label for="female">Female</label>
    <br><br>

    <!-- Dropdown Selection -->
    <label for="country">Country:</label>
    <select id="country" name="country">
        <option value="bd">Bangladesh</option>
        <option value="usa">USA</option>
    </select>
    <br><br>

    <!-- Textarea (বড় মেসেজের জন্য) -->

    <br><br>

    <!-- Submit Button -->
    <button type="submit">Register</button>

</form>

🧱 Semantic Tags & Layout

শুধু <div> ব্যবহার না করে, অর্থপূর্ণ ট্যাগ ব্যবহার করা, যা SEO এবং স্ক্রিন রিডারদের জন্য দারুণ।

🗺 Basic → Pro Roadmap

ধাপে ধাপে HTML এক্সপার্ট হওয়ার পথ।

🟢 Stage 1 — HTML Basics Basic
  • VS Code Setup ও Boilerplate (Emmet) বোঝা।
  • Tags, Elements এবং Attributes এর ধারণা।
  • Heading (h1-h6) এবং Paragraph (p)।
  • Links (Anchor Tag) এবং Image যুক্ত করা।
  • Lists (ul, ol, li) তৈরি করা।
🔵 Stage 2 — Intermediate Mid
  • Complex Tables (rowspan, colspan, thead, tbody)।
  • HTML Forms (input types, label, textareas)।
  • Form validation (required, min, max, pattern)।
  • Media tags (audio, video, iframe)।
  • Text formatting (strong, em, mark, del)।
🟠 Stage 3 — Advanced & Semantic Advanced
  • Semantic Tags (header, footer, main, article, section)।
  • SEO মেটা ট্যাগ এবং Open Graph (OG) ডাটা।
  • <details>, <summary>, <dialog> এর ব্যবহার।
  • SVG এবং Canvas এর বেসিক ধারণা।
🔴 Stage 4 — Pro Expert / Web APIs
  • Web Accessibility (a11y) এবং ARIA Attributes।
  • HTML5 Web Storage (Local Storage & Session Storage)।
  • Geolocation API (কোড দিয়ে ইউজারের লোকেশন বের করা)।
  • Web Workers এবং Service Workers এর তাত্ত্বিক ধারণা।
